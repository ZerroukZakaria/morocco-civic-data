# Source data

`parlement-elections-2021-1-0.xlsx`

"Résultats des élections législatives marocaines de 2021, listes locales et régionales"
Association Tafra. Rabat. 2022. Version 1.0.0 (February 2022).
Obtained from: https://open.africa/dataset/elections-legislatives-maroc-2021
Licence: CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/)

Tafra states that the results were copied from elections.ma, and that the source
reports neither the number of registered voters nor the rate of spoilt votes.

The file is included unmodified. The project's database is a transformed
(unpivoted and normalized) version of it, and keeps this attribution.
